# K-POP FREEBIE website draft

Four pages are proposed: `freebie.html`, `freebie-privacy.html`, `freebie-terms.html`, `freebie-support.html`. English, Turkish, German, French, Spanish, Italian, Japanese and Korean content is included. The publisher/contact follows the current SLYMN site: Süleyman Varol and smanvar4255@gmail.com.

These pages describe a product in development, not a released app or live purchase offer. Illustrations are explicitly labeled as design previews. The OpenAI service is not connected; activation is deferred until launch. No API key is included here. No App Store download button is invented.

The agreed product source is the uploaded Claude instruction package: one free design, weekly €1.99/50 suggestions per subscription week, yearly €39.99/200 per subscription month, no carryover and no AI usage for normal tools. These are proposed prices; Apple’s local purchase confirmation governs actual price and period.

Before the privacy notice becomes a final release notice, compare it against the actual app, RevenueCat configuration and backend. Complete the real server host, retention rules, subprocessors, transfer safeguards and controller details required for the release. The draft explicitly leaves these service details pending; it does not claim compliance has been verified. The actual AI photo processing disclosure must be accepted before any transmission.

Local Bangers font files retain their original SIL OFL 1.1 notice at `assets/freebie/OFL.txt`. The four home illustrations come from the user-supplied asset package. No external font, advertisement or analytics scripts are added by these pages.
